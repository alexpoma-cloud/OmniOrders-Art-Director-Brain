# 📚 Visual Dictionary & Metaphors

**Objective:** Use this dictionary to translate abstract business concepts from the Voice-Over into physical, highly textured metaphorical objects for the center of the composition. 

### 🚨 CHAOS MODE METAPHORS (Problems / Errors)
When the script mentions these concepts, use these physical objects as the `Center`:

* **"Origin Mismatch" / Bans:** A torn geographical map with a massive red marker 'X' over it, or a physical warning notice stamped with 'DENIED'.
* **Wasted Money / Unexpected Costs:** A burning physical invoice, a heavy weight scale tipped the wrong way, or a bleeding physical wallet.
* **SLA Failures / Time Running Out:** A smashed stopwatch, a physical report card with an 'F' grade, or a calendar with aggressively crossed-out dates.
* **System Disconnect / Bad Routing:** Tangled physical cables, broken gears, or a glowing but glitching smartphone screen.

### ✅ CONTROL MODE METAPHORS (Solutions / Success)
When the script mentions these concepts, use these physical objects as the `Center`:

* **Correct Routing / Architecture:** Interlocking clean metallic gears, a glowing clean dashboard, or a pristine architectural blueprint.
* **Savings / Margins:** A glowing calculator showing a high profit margin, a neat stack of crisp dollar bills tied with a band, or a clean financial ledger.
* **Playbooks / Rules:** A clean, open notebook titled 'Operator Playbook', a pristine miniature warehouse model, or crisp flashcards.
* **Automation / Syncing:** Glowing fiber optic cables, perfectly aligned dominoes, or a clean smartphone showing a smooth progress bar.

**General Rule for Objects:** Never use generic 3D icons. Objects must feel real, tactile, and physical (e.g., "a physical paper invoice", "a wooden warehouse model", "a glowing screen").
